# Flashcard Management System

A C++ project built using Object-Oriented Programming to make studying and revising easier through flashcards.

## Features
- Create and manage flashcards.
- Track mastery scores based on correct and incorrect answers.
- Unlock cards based on prerequisite completion.
- Organize cards into categories like Math, Vocabulary, Grammar and Formula.
- View learning progress.
- Save and load flashcards using file handling.

## Concepts Used
- Classes and Objects
- Inheritance
- Polymorphism
- Virtual Functions
- Dynamic Memory Allocation
- STL Vectors
- File Handling

## Tech Stack
- C++
- Microsoft Visual Studio

## How to Run
1. Clone or download this repository.
2. Open the .sln file in Visual Studio.
3. Build and run the project.
4. Make sure cards.txt is available in the working directory.
